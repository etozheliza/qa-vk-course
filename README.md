# qa-vk-course

Этот репозиторий содержит мои практические задания с курса по QA от VK:

- Написание тест-кейсов с применением техник тест-дизайна
- API тестирование (Postman, Swagger)
- SQL практика (JOIN, UNION, GROUP BY, подзапросы)
- Работа с Bash (анализ логов, команды терминала)
- Настройка Docker + PostgreSQL
- Мобильное тестирование (ADB, Android Studio)
- Работа с Charles Proxy

## Структура репозитория:

- /test-cases - тест-кейсы с применением техник тест-дизайна
- /API - коллекции Postman и задания по Swagger
- /SQL - SQL запросы и задания по базе данных
- /bash - команды терминала и анализ логов
- /mobile - команды ADB и практика в Android Studio
- /charles - практика работы с Charles Proxy, перехват и анализ трафика
